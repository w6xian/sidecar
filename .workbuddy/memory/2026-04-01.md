# 2026-04-01 工作日志

## 新增三类指令功能（编译通过）

### 1. 更新指令（UPDATE / UPDATE_ACK）
- 服务端通过 `POST /admin/cmd/update/{connID}` 下发更新指令
- 客户端下载新版本二进制、SHA256 校验、替换文件、重启自身
- 新文件：`internal/sidecar/cmd_update.go`

### 2. 执行 Lua 脚本（EXEC_LUA / EXEC_LUA_RESULT）
- 使用 `github.com/w6xian/gua` 库（已从间接依赖升级为直接依赖）
- 服务端通过 `POST /admin/cmd/exec-lua/{connID}` 下发脚本
- 支持脚本字符串 or 本地文件路径，支持环境变量注入，支持超时控制
- 新文件：`internal/sidecar/cmd_lua.go`

### 3. 上传文件/日志（UPLOAD_FILE / UPLOAD_FILE_DATA）
- 服务端通过 `POST /admin/cmd/upload-file/{connID}` 请求文件
- 支持读全部内容 or 仅读尾部 N 行（tail 参数），限制 max_bytes（最大 32MB）
- 文件内容 base64 编码后回传
- 新文件：`internal/sidecar/cmd_upload.go`

### 协议变更（internal/protocol/）
- `types.go`：新增 6 个消息类型常量
- `message.go`：新增 UpdatePayload、UpdateACKPayload、ExecLuaPayload、ExecLuaResultPayload、UploadFilePayload、UploadFileDataPayload

### 服务端变更
- `handler.go`：handleMessage 新增 UPDATE_ACK/EXEC_LUA_RESULT/UPLOAD_FILE_DATA 分发；新增 SendUpdate/SendExecLua/SendUploadFile 三个方法
- `gateway.go`：新增三个管理 API 端点

### 客户端变更
- `client.go`：handleMessage 新增 MsgUpdate/MsgExecLua/MsgUploadFile 分发

## 新增管理接口：列出所有 Sidecar

- `GET /admin/sidecars` — 返回所有在线 Sidecar 的 connID、alias、服务注册列表
- Hub 新增 `SidecarInfo` 类型和 `ListConns()` 方法
- 编译通过 ✅

## 新增功能：写文件（分段写入）

### 协议
- `WRITE_FILE_CHUNK`（Server→Local）：`WriteFileChunkPayload`，含 path/seq/total/is_final/data(base64)/perm
- `WRITE_FILE_ACK`（Local→Server）：`WriteFileACKPayload`，含 seq/success/bytes_written/error

### 客户端
- 新文件 `internal/sidecar/cmd_writefile.go`
- `writeFileSession` 管理并发多文件写入状态
- `seq==0` 时自动 `MkdirAll` + 创建/截断文件，`IsFinal` 时关闭并回传总字节数
- 每块收到后立即回 ACK，保证串行顺序

### 服务端
- `handler.go`：新增 `WriteFileRequest`/`WriteFileResult`/`SendWriteFile`，切块串行发送，每块等 ACK
- `gateway.go`：新增 `POST /admin/cmd/write-file/{connID}`
- 编译通过 ✅
